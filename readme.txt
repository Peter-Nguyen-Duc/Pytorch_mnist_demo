
= Mnist training template


This code is for demonstrating pytorch neural network options while training on the mnist dataset.

In the code several coding subjects are demonstrated and explained such as:
 - Network update in pytorch
 - Different neural network models with different outcomes
 - The use of all prevalent activation functions + a residual connection example
 - GPU acceleration, might not be efficient i just smacked enough stuff onto the GPU until the compiler stopped screaming at me. and the code became visible in GPU ram.
